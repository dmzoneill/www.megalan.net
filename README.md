The site for MegaLAN, a LAN gaming event.

## Contents

PHP pages for news, events and event sign-up, member sign-up and a member
control panel, clans and ladders, the LAN schedule, galleries, directions,
accommodation, an FAQ, advertising and polls, plus a phpBB forum.

## Tech

- PHP and MySQL

This is an archive of an old site, kept for reference.
